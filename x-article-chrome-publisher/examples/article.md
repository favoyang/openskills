This example validates Markdown parsing for X Articles.

## Why This Workflow Helps

The skill keeps **Markdown formatting**, [links](https://x.com), and lists
intact by pasting generated HTML as rich text.

- Parse the Markdown.
- Paste the body.
- Insert media after the body is in place.

```sh
python3 scripts/parse_markdown.py examples/article.md
```

> Drafts should be reviewed before publication.
